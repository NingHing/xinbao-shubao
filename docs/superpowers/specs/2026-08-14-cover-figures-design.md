# 并记封面小人改画

日期：2026-08-14  
范围：只改 Figma 封面画框里的两个小人。路、标题、构图、进门表单、内页都不动。

Figma：<https://www.figma.com/design/4BK2xZdXUEroLfNaNnTwXQ/Untitled>  
画框：`并记 · 封面`（`9:2`）  
小人编组：稍矮 `9:8`，稍高 `9:11`。只改这两个编组，不要重画路（`9:3`）和「并记」（`9:4`）。  
参考：本机 `Downloads/火柴人.PNG`（方块 + 任意线 / 懒人画画）。学它的线、色、衣服，不学方头。

## 不变

封面仍是现在的线稿结构：

- 白底，大量留白
- 两人站在分叉口，内侧手牵手
- 左下、右下两条线收到脚下，中间一条竖线向上
- 「并记」横放在下面三角里
- 左边的人略矮，右边的人略高
- 站位、身高差、腿的张开、牵手位置，全部按现在 Figma，不重排

## 小人

改成背面。面向画面上方的路，背对观看者。

- 头是空心圆，只画后脑勺。不画五官、不画头发、不画面颊
- 两件衣服剪裁相同：后领一条、后背竖纹、身上色块。结构一样，只换颜色。不当男女装（不要裙子对裤子、长发对短发；不要一个横纹一个竖纹）
- 左边稍矮的人：钴蓝衣服
- 右边稍高的人：橘橙衣服
- 四肢加粗，带手绘抖动；手脚仍是线的末端，不画连指手套，不画手指
- 动势线极少，用该人衣服上的蓝或橙，短、浅，表示手绘，不像在跑
- 牵着的手仍在两人中间，背面也要能看出是手牵手

## 质感

人身上的线比现在的矢量细线明显粗一截，粗细不均，带蜡笔颗粒和轻微抖动。不要粗到在封面这个尺寸里糊成一团。

衣服平涂，带颗粒，可以涂不满、略出线。不要渐变、不要阴影、不要立体。

圆头用同一套粗、抖的黑线，空心，不填色。

## 路

路保持现在的位置和形状，仍是黑线，仍比人细，基本走直。不要画成蜡笔乱涂。人和路要有差别：人是简笔画，路是封面骨架。

## 字

「并记」仍用字，不要手写，不要画进插画里。继续横放在三角里，黑色，位置和现在 Figma 一样。不要蓝、不要橙。字体保持现在的干净无衬线，不要宋体，不要装饰笔画。

## 颜色

只准用这四种：

| 用途 | 色 |
| --- | --- |
| 背景 | 纯白 `#FFFFFF` |
| 轮廓、路、标题 | 黑 `#111111` |
| 左人衣服、其动势线 | 钴蓝 `#2F5BFF` |
| 右人衣服、其动势线 | 橘橙 `#F25C28` |

蓝橙只出现在衣服和极少的动势线上。

## 不做

- 不改进门表单和内页
- 不重排构图，不改画框比例
- 不把「并记」生成进图里
- 不改方头
- 不画正面、五官、头发
- 不加风景、道具、第三个角色
- 不大改四肢姿势；牵手保留

## 验收

打开 `并记 · 封面`，应同时成立：

1. 两个人仍在原位牵手，能看出背面、圆头、无五官
2. 衣服同款异色：左钴蓝、右橘橙；能认出领和条纹
3. 人的线粗、抖、有颗粒；路仍细、直、黑
4. 三角里仍是排版出来的「并记」，不是手绘字
5. 不像一男一女的配对插画
