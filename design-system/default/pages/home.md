# 并记 · 视觉方向（当前）

主参考：根目录 `DESIGN.md`（Airbnb 版式 + 并记纸色）。

## 风格关键词

1. 照片优先、大圆角、主色稀缺（Airbnb 空间语言）
2. 纸张噪点肌理（全屏颗粒）
3. 低饱和莫兰迪纸色，不是珊瑚红市场风

## 色板

以 `styles.css` `:root` 和 `DESIGN.md` 为准。

| Token | Hex | 用途 |
|-------|-----|------|
| `--bg` | `#D8CFC0` | 暖纸桌面 |
| `--panel` / `--card` | `#F7F1E6` / `#FAF6EE` | 面板 / 卡片 |
| `--ink` | `#2C2620` | 主文字 |
| `--muted` | `#7A7064` | 次文字 |
| `--accent` | `#3D5A5B` | 唯一主 CTA（少用） |

## 实现要点

- `body::before` 固定噪点层
- 系统字体，不加 Google Fonts
- 足迹等有图模块：上图下文，圆角 14–20px
- 五个入口保持圆形，莫兰迪分色
